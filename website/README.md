# Траст Строй / Eurasia De Luxe

Локальный сайт на Astro, TypeScript, React и GSAP. Пять статических страниц: главная застройщика, комплекс и три квартиры. Публикация не выполнялась.

## Запуск

Нужны Node.js 22.12+ и Bun 1.3.14+. Из корня репозитория:

```sh
bun install --cwd website --frozen-lockfile
bun run dev
```

Открыть адрес, который напечатает сервер. Стандартный порт — 4321; если занят, Astro выберет следующий. Скрипт работает в foreground, поэтому его можно остановить Ctrl+C. Polling включён для обновления файлов в окружениях с ограниченным доступом к файловым событиям.

## Подготовка медиа на новом checkout

Оптимизированные файлы в `public/media/` воспроизводимы и исключены из Git. Сначала подготовить их из сохранённых оригиналов:

```sh
python3 -m venv /tmp/eurasia-media-venv
/tmp/eurasia-media-venv/bin/pip install -r website/scripts/requirements.txt
/tmp/eurasia-media-venv/bin/python website/scripts/prepare_media.py
```

Скрипт использует ffmpeg из PATH, `FFMPEG_BINARY` или пакета imageio-ffmpeg. Обрабатывает 24 исходных видео и создаёт три 3-секундных приближения по фото, не меняя исходники. Генерирует 1440 px и 864 px H.264 MP4, ключевой кадр каждые 6 кадров, faststart, без аудио. Дополнительно создаёт WebP-постеры, планы и изображения бренда. Повторный запуск пропускает актуальные файлы; после изменения параметров кодирования удалить соответствующие производные файлы и запустить снова.

Раскадровка сгруппирована по помещениям: у 36,67 м² прихожая 01/08, гостиная 03/06, кухня 04/07, ванная 02, лоджия 05. У 39,87 м² тот же порядок без 08. У 79,79 м² порядок 01/02, 03/04, 05/06, 07, 09/10, 11, 13/14.

## Проверки и сборка

```sh
bun run check
bun run test
bun run build
bun run --cwd website test:build
```

- `check`: типы TypeScript и шаблоны Astro.
- `test`: границы скролла, состав медиа, WhatsApp, загрузка соседних сцен, уменьшенное движение, ошибки и повторная загрузка, смена режима.
- `test:build`: все пять HTML-страниц, внутренние ссылки, локальные изображения и метаданные.
- Результат: `website/dist/`. Для просмотра сборки: `bun run --cwd website preview`.

## Контент и контакт

`src/data/apartments.ts` содержит квартиры, подписи и порядок сцен. `src/data/timeline.ts` задаёт переход между сценами в последних 10% участка скролла. `src/components/ApartmentTour.tsx` реализует общую экскурсию, загрузку максимум трёх соседних клипов и альтернативные режимы.

Скопировать `.env.example` в `.env` в папке `website`, затем задать:

- `PUBLIC_SITE_URL`: окончательный HTTPS-адрес сайта без пути.
- `PUBLIC_WHATSAPP_NUMBER`: подтверждённый номер в международном формате, только цифры.

После изменения переменных нужна новая сборка. Без номера вместо фиктивной кнопки показывается сообщение о контактах. Без окончательного домена canonical и абсолютные изображения Open Graph намеренно отсутствуют. Тесты номера используют вымышленное значение и не открывают WhatsApp.

На все детальные страницы назначены собственные названия, описания и изображения. Фасад взят из предоставленной рекламной визуализации с удалением областей старой цены и интерфейса соцсети. Новые рекламные характеристики, наличие и стоимость не выдумывались. Карточка для соцсетей создана отдельно; она не является визуализацией фактической планировки.

## Размещение

Нужен статический хостинг с правильным обслуживанием каталогов `index.html`, MP4 `Content-Type: video/mp4` и HTTP Range (206). Копировать весь `dist/`, включая `_astro/` и `media/`. Для HTML — короткий кэш; для хешированных `_astro/` — immutable; для медиа с текущими стабильными именами — revalidation, без бессрочного immutable-кэша. Публикация и выбор домена оставлены отдельным этапом согласно согласованному плану.

Перед публичным запуском: получить подтверждённый контакт и домен, проверить медленную мобильную сеть и Safari на реальном iPhone. Эмуляция размеров окна не заменяет такую проверку. Временные ограничения зафиксированы в `docs/website/VALIDATION.md` в корне репозитория.
