### Выбранный принцип производства и ограничения

Для планируемой экскурсии рекомендуемый путь: **планировка → проверенная 3D-сцена → рендеры из зафиксированных камер → при необходимости локальная AI-доработка → сверка с исходным рендером**. Рекомендация ещё не означает, что модели созданы или визуальный стиль утверждён.

Генерация изображения по фотографии подходит для пробы стиля или отдельного кадра, но сама по себе не фиксирует устройство квартиры между разными ракурсами. Автоматически сгенерированный из картинки 3D-объект тоже необходимо проверять по плану: неизвестные размеры и невидимые помещения нельзя считать восстановленными достоверно.

Для финала использовать рендер камеры, а не скриншот рабочего интерфейса. Мебель и крупные элементы интерьера лучше закрепить в самой сцене. AI-доработка не обязательна, если рендер уже устраивает; каждый изменённый кадр проверяется заново. Для видео основой остаётся 3D-анимация: независимая обработка кадров может создавать мерцание и менять детали.

Фотографии фасадов нужны для внешнего вида дома и окружения. Полная 3D-модель всего здания для экскурсии по трём квартирам на этом этапе не требуется. Четыре фотографии с разных сторон не следует считать достаточным набором для точного восстановления здания в 3D.

Основание рекомендации по согласованности ракурсов: [Multi-View Depth Consistent Image Generation, 2025](https://arxiv.org/abs/2503.03068) исследует специальные ограничения глубины, структуры и стиля для архитектурных изображений; [Novel View Synthesis with Diffusion Models](https://3d-diffusion.github.io/) показывает необходимость согласования видов сверх обычной генерации по одному изображению. Это обоснование подхода, а не гарантия точности конкретного инструмента.

## Этап 2. 3D-модели в Blender

Для каждого уникального типа квартиры создаётся отдельная Blender-сцена.

Для трёх выбранных квартир принята высота потолков 3,00 м со слов владельца. При детализации требуется уточнить отсчёт относительно чистового пола и потолка.

В сцене должны быть:

- геометрия стен строго по плану;
- входная и межкомнатные двери;
- окна, лоджии и наружные стены;
- кухня, санузлы, встроенные шкафы и ключевая мебель;
- материалы, свет и вид из окон;
- камеры для будущей экскурсии.

Blender-модель является основой. Она фиксирует геометрию и связи помещений; AI не должен менять планировку, окна, двери и размеры комнат.

## Этап 3. Маршрут экскурсии

Для каждой квартиры утверждается последовательность кадров от входной двери до последнего помещения.

Пример:

`Вход → прихожая → гостиная → кухня → лоджия → спальня → санузел`.

Для каждого кадра фиксируются:

- номер;
- помещение;
- положение камеры;
- направление взгляда;
- дверь или проход, через который посетитель пришёл;
- следующее доступное помещение.

## Этап 4. Фотографии

5. Кадры всех лоджий.
6. Кадры всех санузлов.
7. Один или два общих кадра главной зоны квартиры.

Ориентир: 7–12 финальных изображений на один уникальный тип квартиры. Файлы нумеруются по маршруту: `01-entry-hall`, `02-living-room` и далее.

Рендер Blender используется как основной кадр. AI допускается для контролируемого улучшения света, текстиля, растений и мелких деталей после фиксации геометрии.
