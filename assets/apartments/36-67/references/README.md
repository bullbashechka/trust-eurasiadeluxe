# Референсы квартиры 36,67 м²

**Демонстрационная визуализация.** Авторский вариант интерьера в направлении «Тёплый современный» по [дизайн-системе](../../../../DESIGN_SYSTEM.md) и [плану квартиры](../source-plan%20(%D1%84%D0%BE%D0%BD%20%D1%83%D0%B4%D0%B0%D0%BB%D0%B5%D0%BD).png).

Порядок просмотра начинается с входа в квартиру:

| Кадр | Помещение | Промпт |
| --- | --- | --- |
| [01 — Прихожая](01-hallway.png) | 5,20 м², выбранная пользователем основная фотография | [Текст](01-hallway.prompt.txt) |
| [02 — Санузел](02-bathroom.png) | 4,09 м² | [Текст](02-bathroom.prompt.txt) |
| [03 — Кухня](03-kitchen-v2.png) | Вид от входа из холла по основной фотографии: гарнитур слева, лоджия впереди | [Текст](03-kitchen-v2.prompt.txt) |
| [04 — Гостиная](04-living-room-v2.png) | 16,36 м², диван развёрнут налево по основной фотографии | [Текст](04-living-room-v2.prompt.txt) |
| [05 — Лоджия](05-loggia.png) | 3,67 м², учитываемая площадь 1,83 м² | [Текст](05-loggia.prompt.txt) |

Использован встроенный инструмент image_gen. Пользователь выбрал `01-hallway.png` основной фотографией. По ней создана новая гостиная `04-living-room-v2.png`: диван справа в кадре, сиденьями налево, телевизор слева; сохранены кремовая обивка, дуб, шторы и круглый подвес. Предыдущие варианты сохранены отдельно. [Концепция и пространственные ограничения](ART_DIRECTION.md) зафиксированы для всей серии; исходные изображения сохранены без изменений.

Кухня `03-kitchen-v2.png` также перегенерирована встроенным image_gen непосредственно по выбранной фотографии прихожей: слева молочный гарнитур с высокой колонной техники, рядом компактный дубовый стол с прямоугольной скруглённой столешницей и деревянные стулья; впереди остеклённый выход на лоджию. Сохранены светлый дубовый пол, светлая отделка и встроенные потолочные светильники. Приоритет — соответствие видимому из холла интерьеру.

Референсы показывают предполагаемую атмосферу и отделку. Это генеративные изображения, а не ракурсы единой обмерной 3D-модели: геометрия, мебель и мелкие детали между кадрами могут различаться. Для точной реализации потребуется проверка размеров и привязок по рабочим чертежам.
