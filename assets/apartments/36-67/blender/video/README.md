# Проходка по квартире

`apartment-36-67-walkthrough.mp4` — одно непрерывное видео, 60 секунд, 1280 × 720, 24 кадра/с, H.264, без звука.

В начале открывается входная дверь. Камера проходит через квартиру на высоте 1,62 м, делает остановки и поворачивается внутри помещений. Переходы между комнатами проходят через предусмотренные планом двери.

| Время | Действие |
| --- | --- |
| 00:00–00:07 | Открывание двери, вход в прихожую |
| 00:07–00:17 | Вход в санузел, осмотр ванны, раковины и нижней части помещения |
| 00:17–00:22 | Выход из санузла, переход через прихожую |
| 00:22–00:33 | Гостиная: диван, окно, поворот к телевизору |
| 00:33–00:39 | Возвращение через прихожую к кухне |
| 00:39–00:46 | Кухня: гарнитур и обеденная зона |
| 00:46–00:52 | Подход к двери и выход на лоджию |
| 00:52–01:00 | Осмотр лоджии, заключительный вид обратно в кухню |

`apartment-walkthrough.blend` содержит сцену с анимацией камеры и входной двери, освещение для видео и настройки MP4. `walkthrough-route.json` хранит положения камеры и временные отметки.

В макете использованы приблизительные размеры по исходной картинке, мебель и материалы упрощены. Площадка перед входной дверью добавлена только для начала проходки; её нет на исходном плане квартиры. Основная сцена и ранее сделанные фотографии сохранены отдельно.

Повторный рендер на этом Mac из корня проекта:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background assets/apartments/36-67/blender/video/apartment-walkthrough.blend --python assets/apartments/36-67/blender/render_walkthrough.py
```

Полная пересборка анимации из базового макета:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background assets/apartments/36-67/blender/apartment-36-67.blend --python assets/apartments/36-67/blender/make_walkthrough.py
```

Путь камеры проверен во всех 1 440 кадрах: пересечений со стенами не обнаружено. После пересборки для экспорта MP4 нужно выполнить команду рендера.
