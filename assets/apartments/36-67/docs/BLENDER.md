# Макет квартиры по плану 36,67 м²

Редактируемая сцена Blender и ракурсы одной квартиры. Это демонстрационный макет для проверки пространства и последующей генерации фотографических интерьеров. Мебель и сантехника упрощены; все ракурсы получены рендерингом одной 3D-сцены.

## Файлы

- `../blender/apartment-36-67.blend` — стены, полы, потолок, двери, окна, мебель, свет и камеры. Исходная планировка упакована внутрь файла. Внешние текстуры не требуются.
- `../renders/` — 9 видов комнат, план сверху и общий объёмный вид. Комнаты: 1600 × 1100 px; общие планы: 1600 × 1500 px.
- `../blender/build_apartment.py` — воспроизводимый скрипт сборки и рендера.
- `../blender/scene_manifest.json` — координаты камер, масштаб и сопоставление площадей.

## Геометрия

Вход расположен сверху исходного плана. Из прихожей отдельные двери ведут в санузел, гостиную и кухню. Между кухней и гостиной сплошная перегородка. На лоджию можно попасть только из кухни. Положение гарнитура и дивана соответствует исходному плану; существующие генеративные референсы использованы как ориентир для палитры.

Высота потолка принята 3 м по дизайн-системе проекта. Двери, окна, толщина стен и размеры мебели восстановлены приблизительно. Размерных цепочек и высот на предоставленной картинке нет.

Масштаб получен по площади санузла: 0,017342 м на пиксель. Контуры остальных помещений обведены по растровому изображению без искусственного растягивания отдельных комнат. Поэтому чистые площади модели отличаются от подписей на плане:

| Помещение | Подпись на плане, м² | Обведённый чистый пол, м² |
| --- | ---: | ---: |
| Прихожая | 5,20 | 5,00 |
| Санузел | 4,09 | 4,09 |
| Кухня | 9,19 | 8,87 |
| Гостиная | 16,36 | 15,52 |
| Лоджия | 3,67 | 3,67 |

36,67 м² — обозначение квартиры на исходнике, а не результат точного обмера модели. Лоджия на плане учитывается с коэффициентом 0,5: 1,83 м². Эта сцена предназначена для визуализации, не для изготовления мебели или строительной разбивки.

## Работа в Blender

Файл открывается с общим видом. Потолок скрыт только в рабочем окне, при рендере комнат он включён. Объекты разложены по коллекциям; помещения и камеры подписаны.

Для просмотра сохранённого вида из прихожей нажмите `Numpad 0`. Для другого ракурса выберите камеру из коллекции `06 Cameras` и назначьте её активной камерой через меню `View → Cameras → Set Active Object as Camera`. `F12` запускает рендер текущей камеры. На Mac функциональная клавиша может требовать `Fn`.

Камера `10-walkthrough` содержит ключевые позиции маршрута: прихожая → санузел → прихожая → гостиная → прихожая → кухня → лоджия. Назначьте её активной, перейдите к первому кадру и запустите воспроизведение. Скрипты `../blender/make_walkthrough.py` и `../blender/render_walkthrough.py` подготавливают и рендерят минутную проходку с открыванием входной двери. Результаты сохраняются в `../walkthrough/video/`; сейчас готового видео в рабочей папке нет.

Для рендера камер `00` скройте коллекцию `03 Ceilings` именно от рендера. Для интерьерных кадров включите её обратно. Скрипт делает это автоматически.

Повторная сборка и все рендеры на этом Mac:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python assets/apartments/36-67/blender/build_apartment.py
```

Команда пересоздаёт сцену в `../blender/` и PNG в `../renders/`. Сохраните ручные изменения под другим именем перед повторной сборкой. Для сборки без рендера добавьте `-- --no-render`, для быстрых пробников — `-- --preview`.

## Последующая генерация фотографий

Используйте PNG нужной комнаты как геометрический референс. Сохраняйте положение камеры, стен, дверей, окон и основных предметов. Меняйте фактуры и детализацию, сохраняя общую планировку. Для соседних комнат прикладывайте также вид сверху, чтобы генерация учитывала их взаимное расположение. Сами по себе генеративные изображения не гарантируют сохранения размеров, поэтому сверяйте результаты с этой сценой.

Проверено в Blender 5.2.1 LTS, Cycles, Apple M3 / Metal. Официальная документация сохранения сцены: https://docs.blender.org/api/current/bpy.ops.wm.html
