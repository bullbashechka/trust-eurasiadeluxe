# Макет квартиры 39,87 м²

Демонстрационная визуализация по `../source-plan.png`. Все 11 изображений получены из одной сцены Blender; стены, мебель, материалы и свет между интерьерными ракурсами не меняются. Для двух общих видов отключён потолок и добавлен студийный заполняющий свет. Генеративные изображения в этот комплект не входят.

## Открыть результат

- `apartment-39-87.blend` — редактируемая сцена с мебелью, сантехникой, светом, 11 статичными камерами и анимированной камерой маршрута.
- [gallery.html](gallery.html) — автономная галерея: открыть в браузере, нажать изображение для полного размера. Интернет не нужен.
- [gallery.jpg](gallery.jpg) — контактный лист всех 11 ракурсов.
- `renders/` — 9 интерьерных PNG 1600 × 1100 и 2 общих PNG 1600 × 1500.
- [route-contact.jpg](route-contact.jpg) и `route-preview/` — 22 ключевых вида маршрута.
- `scene_manifest.json` — масштабы, площади, координаты всех камер и точки маршрута.
- `validation.json` и [VALIDATION.md](VALIDATION.md) — результаты проверки.
- `apartment-39-87-package.zip` — переносимый комплект; распаковывается в папку `39-87/` вместе с исходным планом.

## Геометрия и допущения

Вход сверху исходного плана ведёт в прихожую. Справа расположен санузел, слева гостиная, впереди кухня. Между кухней и гостиной — сплошная перегородка; выход на лоджию есть только из кухни. Диван стоит вдоль левой наружной стены, шкафы — в верхней части гостиной, гарнитур — у правой стены кухни. Круглый обеденный стол и шесть стульев повторяют схему исходника. Ванна стоит у верхней стены санузла, умывальник и унитаз — справа; стиральная машина размещена в нижней левой части. Лоджия дополнена компактной скамьёй, столиком и растением.

Высота потолка 3 м. Кремовая штукатурка, светлый дуб, светлая плитка/камень, молочные фасады, кремовый текстиль и матовая бронза соответствуют образцу 36,67 м². Материалы процедурные; внешние текстуры не нужны. Исходный PNG упакован внутрь `.blend`.

Растровый план не содержит размерных цепочек. Единый масштаб 0,0180609 м/пиксель получен по санузлу 98 × 122 пикселя и площади 3,90 м². Координаты: X вправо, Y вверх исходника, Z вверх сцены; начало XY соответствует пикселю (220, 956). Контуры обведены без индивидуального растягивания комнат под подписи.

| Помещение | На исходном плане, м² | Чистый контур модели, м² |
| --- | ---: | ---: |
| Прихожая | 4,04 | 3,85 |
| Санузел | 3,90 | 3,90 |
| Гостиная | 21,13 | 20,39 |
| Кухня | 9,09 | 8,76 |
| Лоджия | 3,42 | 3,70 |

Исходник указывает 38,16 м² без лоджии и 39,87 м² с половиной её площади: 38,16 + 3,42 × 0,5. Площади модели — результат приближённой обводки; пороги и площадь перегородок в таблицу не включены. Высоты окон и дверей, толщины стен, размеры предметов и открытые положения дверных полотен приняты для визуализации. Навеска кухонной двери выбрана слева, чтобы открытое полотно не перекрывало проход вокруг стола. Входная дверь закрыта; маршрут начинается сразу за ней, внутри прихожей. Это макет, а не обмерный или строительный проект.

## Просмотр в Blender

Сцена открывается общим видом. Потолок скрыт в рабочем окне, но включён в рендере интерьерных камер. Объекты сгруппированы в коллекции: архитектура, полы, потолок, мебель и сантехника, свет, камеры, двери/остекление, исходный план.

`Numpad 0` показывает активную камеру. Для смены ракурса выберите камеру в коллекции `06 Cameras — route through apartment`, затем в 3D-окне `View → Cameras → Set Active Object as Camera`. `F12` — рендер (на Mac может потребоваться `Fn`).

Для анимации выберите камеру `10-walkthrough | Маршрут по квартире`, назначьте активной, перейдите на кадр 1, включите вид камеры и воспроизведение. Диапазон 1–1596, 30 кадров/с, длительность 53,2 с. Маршрут: вход → прихожая → санузел и обратный вид → прихожая → гостиная и окно → прихожая → кухня с обходом стола → лоджия. Точки подписаны маркерами на временной шкале. Позиция интерполируется линейно, с короткими остановками; это редактируемый проверочный маршрут, не готовый кинематографический ролик.

В рабочем окне можно временно включить коллекцию потолка для прогулки. Для рендера камер `00` отключайте потолок именно от рендера; для интерьерных камер включайте обратно. Скрипт сборки автоматически выставляет эти состояния.

## Воспроизведение результата

Из корня репозитория:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python assets/apartments/39-87/blender/build_apartment.py
```

Повторная сборка перезаписывает `.blend`, манифест и итоговые PNG. Ручные изменения сначала сохраните в отдельный файл. Для сборки без рендера добавьте `-- --no-render`. Для пробников 800 пикселей по ширине в `previews/` — `-- --preview`. Для отдельных ракурсов: `-- --only 04-kitchen,07-kitchen-reverse`.

Проверка сохранённой сцены:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python assets/apartments/39-87/blender/validate_scene.py
```

Раскадровка анимированной камеры:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python assets/apartments/39-87/blender/render_route_preview.py
```

Сборка контактных листов, галереи и архива: `python3 assets/apartments/39-87/blender/package_result.py` (нужен Pillow). Скрипты используют пути относительно собственного расположения и работают также после распаковки архива.

## Использование для генерации фотографий

Прикладывайте нужный интерьерный PNG вместе с планом сверху. Сохраняйте положение камеры, стен, проёмов, окон, мебели и сантехники. Улучшайте фактуры и детализацию без изменения планировки. В обратных ракурсах сверяйте те же предметы и материалы. Исходные рендеры в `renders/` оставляйте как геометрическую основу.

Сборка и проверка: Blender 5.2.1 LTS, Cycles, Apple Metal. Структура ключевых кадров сверена с [Blender Python API](https://docs.blender.org/api/current/info_quickstart.html).
