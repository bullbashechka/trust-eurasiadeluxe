# Архивы

Сохранённые комплекты на момент упаковки; внутри может быть прежняя структура папок. Для текущих материалов используйте соседние папки квартиры.

`checksums.json` относится к содержимому сохранённого ZIP. Запуск `../blender/package_result.py` обновляет комплект и контрольные суммы с текущими путями.
