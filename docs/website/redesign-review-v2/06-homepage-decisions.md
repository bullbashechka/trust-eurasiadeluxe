# Главная страница «Траст Строй»: решения

## Основа

- Референс: `06-trust-stroy-composed-reference.png`.
- На компьютере максимально точно повторить композицию референса.
- На телефоне сохранить содержание, расположить блоки вертикально.
- При увеличении текста в браузере сохранять всё содержание, разрешать дополнительные переносы и увеличение высоты блоков. При обычном размере текста следовать референсу. Пользователь согласовал.
- На широких мониторах ограничить ширину содержания и выровнять его по центру; фоны секций и полотно перехода занимают всю ширину экрана. Пользователь согласовал.
- Обсуждать продуктовые пограничные случаи последовательно; технические решения принимает исполнитель.
- Изображение проекта повторяет референс. Пользователь разрешил найти исходник в `refs` и улучшить его. Найден фасад в скриншоте с временем `5.47.59`; подготовить отдельное изображение с закатным небом и озеленением как в макете, сохраняя архитектуру исходника.

## Контактная форма

- В нижнем блоке заменить «Обсудим будущий проект» на «Найдём ваш будущий дом», сохранив оформление референса. Пользователь согласовал замену.

- Кнопки связи открывают форму с именем и телефоном.
- Отправки на сервер и сохранения введённых данных нет.
- Демообозначения не показывать по прямому указанию пользователя.
- После успешной локальной проверки показать «Форма успешно отправлена».
- После закрытия сообщения об успехе повторное нажатие «Связаться» открывает пустую форму для нового заполнения, а не прежнее сообщение. Пользователь согласовал.
- Пока форма открыта, прокрутка фона заблокирована, верхнее меню не реагирует на направление прокрутки. Если форма не помещается на экране, прокручивается её содержимое. После закрытия восстановить прежнюю позицию и обычное поведение страницы. Пользователь согласовал.
- Телефон: только номера Казахстана; пользователь выбрал ограничение местными номерами. Точный набор допустимых кодов проверить при реализации.
- При закрытии и повторном открытии формы сохранять введённые поля только в оперативной памяти страницы, до её обновления. После успешной «отправки» очищать поля. Пользователь согласовал это поведение; постоянное хранение не используется.

## Движение

- Пользователь поручил изучить Motion и Anime.js и реализовать выразительную анимацию.
- Smooth scroll обязателен.
- Рабочее техническое решение: Anime.js для появления элементов и прорисовки чертежа, Lenis для плавной прокрутки.
- Конечные положения элементов соответствуют референсу.
- При быстрой прокрутке сохранять постепенное раскрытие блоков: не сокращать эффекты и не показывать всё мгновенно. Пользователь явно выбрал это поведение. Прокрутку не блокировать.
- Анимация появления обратима и привязана к положению прокрутки: вниз элементы постепенно раскрываются, при движении вверх через тот же участок перехода постепенно исчезают. При повторном движении вниз раскрываются снова. Пользователь явно запросил исчезновение при обратной прокрутке.
- При уменьшении движения в системных настройках отключать декоративное движение.

## Навигация

- Переход в проект согласован: полотно с фотографией дома выезжает справа налево и закрывает весь экран; под ним открывается Eurasia De Luxe; после готовности страницы полотно уезжает вправо. Смена страницы полностью скрыта, без вспышки пустого фона.
- На телефоне фотография перехода заполняет весь экран с обрезкой по бокам; главный корпус остаётся в центре. Пользователь выбрал первый вариант, без однотонных полей.
- При ошибке загрузки проекта полотно уезжает вправо, главная остаётся на прежнем месте. Показать «Не удалось открыть проект» и кнопку «Повторить». Пользователь согласовал.
- Фотография дома и кнопка «Смотреть проект» открывают проект с одинаковым переходом через полотно. На компьютере фотография слегка увеличивается при наведении. Пользователь согласовал.
- Пользователь выбрал третий вариант: верхнее меню скрывается при прокрутке вниз и возвращается при прокрутке вверх.
- В начале страницы меню видно.
- При возврате со страницы проекта на главную восстанавливать прежнее место прокрутки, не повторять вступительную анимацию.
- На телефоне: логотип слева, отдельная кнопка «Связаться» и кнопка меню справа. Пользователь согласовал этот вариант.
