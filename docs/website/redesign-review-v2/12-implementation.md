# Реализация редизайна v2

Страница комплекса и три страницы квартир реализованы локально по утверждённым макетам и решениям из `11-project-page-decisions.md`.

## Выполнено

- `/eurasia-deluxe/`: вечерний первый экран, архитектурная композиция, интерьер, фильтры квартир, карточки с наклоном от курсора, выбор экскурсии, форма и подвал.
- Карточки и выбор экскурсии открывают выбранную квартиру в новой вкладке; возврат к планировкам работает в текущей вкладке.
- Все три страницы квартир получили общий экран с площадью, полноэкранную прокручиваемую экскурсию, план поверх кадра, характеристики, форму и другие планировки.
- Тур использует существующие 27 сцен, хранит ограничение в три соседних ролика, не закрепляется до подготовки видео и даёт явный запуск при поздней загрузке.
- Форма проверяет телефон локально и показывает обычное сообщение успеха без сетевого запроса и хранения значений.
- `prepare_media.py --images-only` воспроизводимо создаёт `project-building.webp`, `architecture-detail.webp` и `project-interior.webp` из сохранённых оригиналов.

## Проверено

- `bun.cmd run --cwd website test`
- `bun.cmd run --cwd website check`
- `bun.cmd run --cwd website build`
- `bun.cmd run --cwd website test:build`

Все команды завершились успешно. Локальный HTTP-ответ `/eurasia-deluxe/` — 200.
