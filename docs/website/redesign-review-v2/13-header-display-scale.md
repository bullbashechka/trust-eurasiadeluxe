# Шапка A и масштаб интерфейса

Реализовано 9 сентября 2026.

- На страницах комплекса и квартир используется фиксированная тёмная полупрозрачная шапка с закруглением, увеличенным логотипом и отдельной кнопкой выбора квартиры.
- Шапки проекта и застройщика больше не скрываются при прокрутке вниз. Шапка застройщика сохраняет собственное оформление.
- Общий Layout включает компенсацию уменьшения масштаба для всех пяти страниц. Размеры текста, отступов и элементов сохраняются относительно исходного масштаба вкладки. Увеличение остаётся стандартным; сочетания клавиш и жесты не блокируются.
- Размеры в единицах viewport и высота тура компенсируются вместе с CSS zoom. Пороговые значения медиазапросов также корректируются, чтобы уменьшение масштаба не включало настольную вёрстку на узком окне.
- Контент продолжает занимать доступную ширину. Это не полотно фиксированной ширины 1440 px; у шапки максимальная ширина 1392 px с внешними полями.

## Ограничения

Браузер не предоставляет отдельное надёжное значение абсолютного масштаба страницы. За исходное значение принимается DPR при первом открытии сайта в этой вкладке; оно сохраняется в sessionStorage. Если первое открытие уже было на 80%, именно этот вид считается исходным. При недоступном хранилище исходное значение сохраняется только до перезагрузки. Для экрана с другими размерами создаётся отдельное исходное значение. Смена системного масштаба или переход между экранами с одинаковыми размерами могут быть неотличимы от браузерного zoom.

## Проверка

Автотесты проверяют уменьшение и увеличение относительно Windows DPR 1.25, перезагрузку, Astro-навигацию, другой экран, недоступное хранилище и стабильность порогов адаптации. В Chrome визуально проверены шапка на широком и узком экране и открытие меню. Нативное изменение браузерного zoom через инструмент автоматизации не подтвердилось: тесты алгоритма не заменяют ручную проверку Ctrl−/Ctrl+ на целевых браузерах.
