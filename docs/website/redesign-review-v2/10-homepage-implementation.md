# Главная «Траст Строй»: реализация

## Выполнено

- Главная пересобрана по `06-trust-stroy-composed-reference.png`: первый экран с векторным зданием, компания, преимущества, проект, контактный блок и подвал.
- Исправленный SVG с 16 углублёнными оконными проёмами подключён непосредственно в разметку. Исходник и генератор сохранены; версия с откосами также находится в Figma (node `13:346`).
- Стили главной изолированы классом `company-page`. Существующие страницы комплекса и квартир сохраняют своё оформление.
- Anime.js: вступление, прорисовка здания и иконок, обратимые появления при прокрутке, форма и полотно. Lenis: плавная прокрутка колёсиком и переходы к разделам, естественное сенсорное прокручивание.
- Меню скрывается вниз и возвращается вверх с порогом 14 px. На телефоне доступны отдельные кнопки связи и меню.
- Локальная форма: имя, проверка номера Казахстана через метаданные libphonenumber-js/max, ошибки полей и сообщение об успехе. Нет API, сетевой отправки или постоянного хранения. Черновик существует только в полях текущего документа до обновления или успешного завершения.
- Общий ClientRouter включён только на главной и странице комплекса. Переход через фотографию ждёт документ, стили и главное изображение; ошибка возвращает интерфейс с повтором. Тайм-аут 15 секунд. Квартиры открываются полноценной документной навигацией.
- Возврат из проекта восстанавливает положение главной и раскрытие блоков без повторения вступления.
- Уменьшение движения: без инерции и декоративных анимаций. Основное содержание доступно без JavaScript.

## Источники изображений

- `assets/brand/eurasia-project-dusk.png`: переработанная визуализация на основе фасада из `refs` и закатного изображения в референсе.
- `assets/brand/company-materials.png`: восстановленная отдельная иллюстрация камня и терракотовой плоскости из референса.
- Astro генерирует оптимизированные WebP и адаптивные размеры. Эти два изображения не зависят от локальных файлов Figma.
- Oswald Variable для узких заголовков, Arial для основного текста; шрифт заголовков хранится в зависимости проекта, без запросов к Google Fonts.

## Проверки

- `bun run check`: без ошибок, предупреждений и подсказок.
- `bun run test`: 4 проверки данных и медиа туров, 4 проверки интерфейса туров, 7 проверок формы и подготовки перехода.
- `bun run build` и `bun run --cwd website test:build`: пять страниц, локальные ссылки, изображения и метаданные.
- Медиа существующих квартир подготовлены штатным скриптом: 27 сцен, варианты desktop и mobile.
- Chrome через Computer Use: ширины 360, 390, 768, 1024, 1440, 1920 px; горизонтального переполнения нет. Проверены мобильное меню, форма, сохранение черновика, успешное завершение, полотно и возврат к проекту.
- На локальной производственной сборке проверено восстановление после HTTP 503 и зависания запроса (15 секунд), затем успешный повтор и возврат. Тестовая неисправность задаётся только сервером проверки в игнорируемой `.cache`, не кодом сайта.
- Контрольные снимки: `10-homepage-desktop.png`, `10-homepage-mobile.png`.

## Практические ограничения

- Это вёрстка по растровому референсу, а не исходный макет со шрифтами: остаются небольшие отличия очертаний букв, деталей иллюстраций и сглаживания. На телефоне композиция намеренно перестроена.
- Реальный iPhone/Safari в этой сессии не проверялся; изменение размера окна Chrome не является такой проверкой.
- Финальный повтор заполнения формы на телефоне был прерван интерфейсом другого расширения Chrome. До этого проверены форма на компьютере, мобильное меню и переходы. Отдельная проверка масштаба 200% не подтверждена инструментом браузера; шесть размеров экрана проверены фактически.
- Публикация и реальный приём заявок не выполнялись согласно согласованному объёму.
