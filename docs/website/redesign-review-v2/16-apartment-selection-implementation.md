# Прямой выбор квартиры

## Реализовано

На `/eurasia-deluxe/` интерьерный баннер и прежний блок с фильтрами заменены одной секцией `#apartments`. Заголовок: «Какая квартира подойдёт вам?». Три реальные планировки — 36,67, 39,87 и 79,79 м² — показаны с площадью, числом комнат и действием «Смотреть квартиру». Вся карточка открывает квартиру в новой вкладке. Якорные ссылки сохранены; тур, связь и подвал остаются ниже.

`ApartmentCards` получил необязательный вариант `variant="selection"`; стандартный вариант и поведение блока «Другие планировки» сохранены. Изображения взяты из существующих данных без генерации или изменения геометрии. Фон исходных изображений сохранён; декоративные растения из референса не перенесены.

## Карусель

- От 1024 px эффективной ширины — три колонки и существующий наклон карточек при наведении.
- Ниже — GSAP Draggable, центральная карточка шириной 84% контейнера, максимум 420 px, промежуток 16 px и края соседних карточек.
- Три исходные ссылки перемещаются по циклической траектории без DOM-клонов. Начальная квартира — 36,67 м². Нет автоматического перелистывания или захвата вертикальной прокрутки.
- Стрелки, клавиши Left/Right и горизонтальное перетаскивание переключают квартиры; привязка при отпускании — к ближайшей карточке. Горизонтальный drag более 8 px подавляет следующий release-click; новое нажатие снова работает как ссылка.
- Анимация 350 мс, при reduced motion мгновенная. Неактивные карточки исключены из фокуса и accessibility tree. Статус объявляет текущую квартиру.
- При resize и смене режима выбранная квартира сохраняется. Геометрия учитывает CSS zoom сайта и обновляется после загрузки шрифтов.
- Без JavaScript — вертикальный список всех трёх доступных ссылок. Кнопки карусели появляются только после инициализации.
- При уходе со страницы очищаются GSAP, Draggable, ResizeObserver и обработчики. Исправлено накопление обработчиков старого эффекта наклона.

## Проверка

Автотесты: циклические индексы и позиции, свайп/тап/вертикальный жест, переходы и фокус с клавиатуры, подавление клика после drag, сохранение выбора при resize/компенсации масштаба, очистка и повторный mount, reduced motion с порядком событий release → dragend.

Build-контракт: ровно одна секция `#apartments`, отсутствие баннера/фильтров, три ссылки с правильными адресами, `target="_blank"`, `rel="noopener noreferrer"`, скрытые до инициализации контролы.

Chrome: проверены desktop и мобильная карусель, реальное перетаскивание мышью, цикл 3 → 1 и открытие квартиры в отдельной вкладке. Контрольные ширины — 320, 390, 768, 1024, 1440 px. Нативные touch-жесты на физическом телефоне и Ctrl−/Ctrl+ требуют отдельной ручной проверки; автоматические тесты покрывают логику масштабирования и распознавания жестов.

Команды: `bun run check`, `bun run test`, `bun run build`, `bun run --cwd website test:build`.

Изменения подготовлены локально, без публикации и без новой аналитики. Рост конверсии не измерялся.
