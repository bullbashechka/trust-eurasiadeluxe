# Страница комплекса: интерьер и отступы

Проверено 9 сентября 2026. Область: `/eurasia-deluxe/`, общая мобильная шапка проекта.

## Результат

Существующая композиция блока интерьера сохранена до выбора нового варианта. При ширине окна 1440 px высота уменьшена с 820 до 480 px, на мобильном — с 510 до 320 px. На промежуточных ширинах применяется плавный диапазон 360–480 px. Заголовок уменьшен пропорционально, нижний градиент усиливает читаемость белого текста. Кадрирование остаётся `object-fit: cover` без деформации изображения.

## Система расстояний

- Общие боковые поля: 24–72 px; на мобильном 24 px.
- Вертикальные поля основных секций: 64–96 px на настольной/планшетной версии, 56 px на мобильной.
- Акцентная полоса тура: 48 px по вертикали, на мобильном 32 px.
- Заголовок → фильтры: 24 px; фильтры → карточки: 32 px, на мобильном 24 px.
- Поля карточек: 24 px; промежуток между карточками: 16 px.
- Фильтры: минимальная высота 44 px для удобного нажатия.
- Подвал: 32 px по вертикали.

Это проектная шкала, а не универсальная норма. Асимметрия фотографий архитектуры и отрицательный отступ фасада сохранены как часть утверждённой композиции. Полноширинные изображения и цветные полосы намеренно выходят за поля текстового контента.

## Исправленные дефекты

1. Подпись «Больше чем просто дом» размещалась в дополнительной строке под EURASIA и пересекалась с буквами. Теперь на desktop у трёх элементов отдельные колонки; на мобильном сохраняется вертикальная композиция.
2. Селектор прокрученной шапки имел большую специфичность и возвращал настольные размеры на мобильном. Мобильные правила теперь покрывают это состояние.
3. В узкой шапке логотип касался кнопки выбора квартиры. Заданы отдельные колонки с промежутком 12 px. До 360 px меню представлено иконкой с доступным названием «Меню».

## Варианты интерьера

Сравнительная доска: [пять референсов](14-interior-five-options.png), подготовлена субагентом Astra с низким уровнем рассуждения.

1. Панорама — наиболее близка текущему макету.
2. Редакционный — текст слева, фотография справа.
3. Карточка — фотография с боковыми полями и скруглением; предпочтительна для связи с карточками и шапкой.
4. Диптих — общий вид и деталь.
5. Лента — отдельный заголовок над узкой панорамой.

Референсы иллюстрируют компоновку; это не скриншоты готовых реализаций.

## Проверка

В Chrome измерены варианты 320, 390, 768 и 1440 px. Горизонтальное переполнение не выявлено; на контрольных ширинах 320, 768 и 1440 px элементы шапки разделены, а настольный заголовок больше не пересекается с подписью. Визуально проверены компактный интерьер и переход к карточкам. Проверки проекта: `bun run check`, `bun run build`, `bun run --cwd website test:build`.
