# Страница квартиры 39,87 м²

Решения по ответам пользователя. Референс — визуальная концепция; реализация сайта в этот этап не входит.

- Отдельная страница `/eurasia-deluxe/apartments/39-87/`, открываемая из карточки планировки.
- Первый экран: общая информация о квартире и переход к туру. Площадь 39,87 м², 1-комнатная, Eurasia De Luxe; краткое описание, кнопки «Начать тур» и «Планировка».
- Тур: прокрутка ведёт камеру по подготовленному маршруту; обратная прокрутка возвращает назад. После тура продолжается обычная страница.
- Телефон: тот же сценарий управления прокруткой, согласно явному выбору пользователя.
- Выбор комнат через мини-план с подсветкой текущей комнаты. Комнаты из данных проекта: прихожая, гостиная, кухня, ванная, лоджия.
- Кнопка «Планировка» открывает увеличенную схему поверх тура. Закрытие возвращает к прежнему месту; открытие приостанавливает движение камеры.
- После тура: характеристики и большая планировка, затем контакты и две другие квартиры (36,67 и 79,79 м²).
- Стиль: второй из двух файлов, находящихся сейчас в папке, `06-trust-stroy-composed-reference.png`. Молочный фон, графитовый текст, терракотовые акценты, высокие узкие заголовки. Фоны секций прямоугольные; изображения и карточки скруглены. Плавающая нижняя навигация отсутствует.
- Исходники: `assets/apartments/39-87/photos/photorealistic/03-living-room.png`, `assets/apartments/39-87/plans/source-plan.png`; сведения о квартире — `website/src/data/apartments.ts`.
- Не добавлять неподтверждённые цену, этаж, сроки, контакты или площади отдельных комнат. Изображения интерьера обозначать как вариант интерьера / визуализацию.

## Детали для реализации

Мини-план синхронизируется с маршрутом и позволяет перейти к комнате. Закрепление кадра действует только в границах тура; доступен выход к характеристикам. На телефоне мини-план располагается под кадром и не закрывает интерьер. Учитывать reduced motion и управление с клавиатуры. Статичный референс показывает внешний вид тура; поведение прокрутки проверяется при реализации.
